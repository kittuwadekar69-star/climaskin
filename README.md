# ClimaSkin — Vercel-Ready Prototype

ClimaSkin is a responsive, climate-aware skincare concept designed to make everyday skincare routines simpler and more sustainable.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Vercel for deployment

## Features
- Interactive location selector: Kolhapur, Pune, Mumbai and Delhi.
- Skincare preference selector.
- Dynamic daily skincare notes and suggested routines.
- Sustainability tips to reduce unnecessary product purchases and packaging waste.
- Responsive design for desktop and mobile devices.
- Green, yellow and pink colour theme.

## Dataset
The prototype uses a small, illustrative dataset containing four fictional location-condition profiles and four skincare preference categories. These examples demonstrate the recommendation interface and do not represent live weather or air-quality readings.

## How to Run Locally
1. Download and extract the project ZIP.
2. Open the project folder.
3. Open `index.html` in a web browser.

Alternatively, use the Live Server extension in Visual Studio Code.

## Deployment on Vercel
1. Upload the project files to a GitHub repository.
2. Open https://vercel.com/new.
3. Import the GitHub repository.
4. Select **Other** as the framework preset.
5. Leave the build command and output directory blank.
6. Click **Deploy**.

## Sustainability Objective
ClimaSkin encourages users to finish existing skincare products before purchasing replacements, consider refill options when available, and avoid unnecessary consumption. Future pilot testing could measure user satisfaction, products finished and packaging waste avoided.

## Limitations and Future Scope
- Connect verified weather, UV-index and air-quality data sources.
- Validate recommendations using credible scientific sources and user testing.
- Evaluate sustainability outcomes through a pilot study.
- Improve accessibility and expand the sample dataset.

**Disclaimer:** ClimaSkin is an early-stage concept prototype, not a medical diagnostic tool. Its sample data and recommendations have not been clinically validated.
