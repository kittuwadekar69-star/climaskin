# ClimaSkin — Vercel-ready prototype

A responsive front-end concept built with plain HTML, CSS and JavaScript. No framework, backend, account or API key is required.

## Run locally
Open `index.html` in a browser, or use VS Code's Live Server extension.

## Deploy to Vercel
1. Extract this ZIP.
2. Upload the five project files to a GitHub repository.
3. Open https://vercel.com/new and import the repository.
4. Select **Other** as the framework preset.
5. Leave Build Command and Output Directory blank, then deploy.

Optional Vercel CLI: install Node.js, run `npm i -g vercel`, then run `vercel` inside this folder.

## Demo data
`app.js` contains four fictional sample profiles (Kolhapur, Pune, Mumbai, Delhi) and four self-selected concerns. The data is illustrative, not live weather or air-quality information. Replace it with verified sources before describing the app as live. This is a general wellness concept, not a diagnostic tool.
